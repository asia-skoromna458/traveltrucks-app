# TravelTrucks

Camper Rental — вебзастосунок для пошуку та бронювання кемперів.  
Користувачі можуть переглядати каталог доступних транспортних засобів, застосовувати фільтри, переглядати детальну інформацію про кемпери, їхні характеристики, фотографії, відгуки та надсилати заявки на бронювання.

## Основний функціонал

- Перегляд списку кемперів, отриманих із бекенду
- Фільтрація за локацією, типом кузова, двигуном і трансмісією
- Фільтрація через query-параметри бекенду
- Довантаження кемперів через кнопку **Load More**
- Перегляд детальної сторінки обраного кемпера
- Галерея зображень із мініатюрами
- Відображення відгуків користувачів із рейтингом у п'ятизірковій шкалі
- Форма бронювання з валідацією полів
- Повідомлення про успішне відправлення заявки

## Сторінки застосунку

### Головна сторінка (`/`)

Містить банер із закликом до дії та кнопку **View Now**, яка перенаправляє користувача до каталогу кемперів.

### Каталог (`/catalog`)

Сторінка зі списком доступних кемперів.

Реалізовано:

- отримання даних із бекенду;
- фільтрацію за:
  - локацією;
  - типом кузова;
  - типом двигуна;
  - типом трансмісії;
- завантаження додаткових карток через кнопку **Load More**.

При кожному натисканні на кнопку завантажуються нові кемпери з урахуванням активних фільтрів.

Кнопка **Show more** у картці кемпера відкриває сторінку деталей у новій вкладці браузера.

### Деталі кемпера (`/catalog/[camperId]`)

Сторінка з повною інформацією про обраний кемпер.

Містить:

- опис та характеристики транспорту;
- фотогалерею;
- відгуки користувачів;
- рейтинг;
- форму бронювання.

Галерея реалізована за допомогою бібліотеки **Swiper**.

Після успішного відправлення форми користувач отримує повідомлення про успішне бронювання.

## Встановлення

Клонуйте репозиторій:

```bash
git clone https://github.com/asia-skoromna458/traveltrucks-app.git
```

Перейдіть у папку проєкту:

```bash
cd traveltrucks-app
```

Встановіть залежності:

```bash
npm install
```

Запустіть застосунок у режимі розробки:

```bash
npm run dev
```

Після запуску відкрийте:

```text
http://localhost:3000
```
